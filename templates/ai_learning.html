This first version is a baseline linear model. It is intentionally simple so the app can train directly from the archived GRIB files without adding a heavyweight ML stack.
Each sample uses the file's run hour, forecast hour, valid hour, date-derived seasonality fields, and the raw archive group so the model can distinguish different feeds such as raw_grib and raw_grib_gust.
